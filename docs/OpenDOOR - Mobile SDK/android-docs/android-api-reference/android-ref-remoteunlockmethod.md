How a door is unlocked remotely.

## Declaration

```kotlin
enum class RemoteUnlockMethod {

    INTERCOM,
    DOOR_SCOUT,
}
```

## INTERCOM

Through the door's intercom.

## DOOR_SCOUT

Through a Door Scout near the door.

Package: `com.door.opendoor.android.core.api.model`.
