  Buildings represent the top-level physical locations in OpenDOOR. They group
  doors, residents, and access permissions under a single property.

Use the Buildings endpoints to:

* Retrieve the list of buildings available to your integration
* Identify where doors and users belong
* Sync your system with the correct property structure

Most integrations start by fetching buildings and using their IDs to scope all subsequent requests.
