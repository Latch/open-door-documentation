Here's how to grant users access to open Doors, step by step:

* Directory Locks Setup: Associate physical Latch Cortex Locks with OpenDoor Directory Items.
* Access Paths Setup: Create Access Paths that define routes between Doors OpenDoor Directory Items of Entrance types
* Permission Sets Setup
* Roles Setup
* Role Assignments

After these steps are completed the User can see and open the Doors it has access to in the Door/SDK mobile apps.
