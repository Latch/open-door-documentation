Here's how to grant users access to open Doors, step by step:

* Directory Locks Setup: Associate physical Latch Cortex Locks with OpenDoor Directory Items of ENTRANCE type.
* Access Paths Setup: Create Access Paths that define routes between Doors in the building.
* Permission Sets Setup: Define Sets of Permissions that define capabilities Roles will have.
* Roles Setup: 
* Role Assignments

After these steps are completed the User can see and open the Doors it has access to in the Door/SDK mobile apps.
